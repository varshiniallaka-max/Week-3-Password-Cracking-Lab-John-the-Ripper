# Password Cracking Lab Using John the Ripper (JTR)

## Overview

This project demonstrates a basic password-cracking exercise performed using Kali Linux and John the Ripper (JTR). The lab focuses on extracting a password hash from a password-protected PDF file and attempting to recover the password using a password-cracking tool.

## Objective

- Understand how password hashes are extracted from password-protected PDF files.
- Learn the basic workflow of password cracking.
- Practice using John the Ripper in Kali Linux.
- Understand the importance of strong passwords and password protection.

## Tools Used

- Kali Linux
- John the Ripper (JTR)
- PDF Hash Extraction Tool
- Terminal

## Practical Workflow

1. Used a password-protected PDF file provided for the lab.
2. Extracted the PDF password hash.
3. Saved the extracted hash in a text file.
4. Used John the Ripper in Kali Linux to attempt password recovery.
5. Identified the recovered password through the cracking process.
6. Verified the recovered password by opening the protected PDF.

## Implementation

Kali Linux was used for this practical. John the Ripper was already available in the Kali Linux environment, so no additional installation was required.

The extracted hash was used as input for John the Ripper, which attempted to recover the password.

## Learning Outcomes

- Gained practical exposure to password hash extraction.
- Learned the basic operation of John the Ripper.
- Understood the relationship between password hashes and password recovery techniques.
- Learned how weak passwords can be vulnerable to cracking attempts.
- Improved familiarity with Kali Linux command-line tools.

## Disclaimer

This project was conducted for educational purposes as part of a cybersecurity lab. Password recovery was performed only on lab-provided files within an authorized learning environment.
